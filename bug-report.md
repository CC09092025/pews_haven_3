| #   | What I saw                           | Where I found it                            | Cause                                                                                                | Fix                                        |
| --- | ------------------------------------ | ------------------------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 1   | Improperly Declared Variable         | `const signedUp = 0;`                       | signedUp was created as a Constant. Constants cannot be reassigned.                                  | `const` -> `let`                           |
| 2   | Improper Comparison                  | `if ((volunteerName = "")) {`               | `volunteerName = ""` assignment operator `=` not `===`                                               | `=` -> `===`                               |
| 3   | Missing Default Behaviour Prevention | `shiftForm.addEventListener("submit", ...)` | The form's default submission behaviour is not prevented, which can cause the page to reload.        | Add `event.preventDefault()`               |
| 4   | Unsafe HTML Insertion                | `item.innerHTML = ...`                      | User-provided input is inserted directly into HTML, potentially allowing cross-site scripting (XSS). | Use `textContent` and DOM elements instead |
| 5   | Incorrect Element ID                 | `#shift-lst`                                | Does not match the HTML's `shift-list` ID.                                                           | `#shift-list`                              |
| 6   | Script Loading Order                 | HTML `<head>`                               | JavaScript executes before the DOM is parsed.                                                        | Add defer                                  |
